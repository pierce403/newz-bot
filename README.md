# Newz Bot

Newz Bot is a modern, AI-powered RSS news feed manager designed to provide personalized analysis, summaries, and ratings for news articles.

## Features

- **Classic RSS Feed Management**: Subscribe to and read your favorite RSS feeds in a clean, efficient interface inspired by Google Reader.
- **AI-Powered Insights**: (Coming Soon) Personalized analysis and summaries of news articles.
- **Self-Hostable**: Run your own instance of Newz Bot.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/newz-bot.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Deployment

Easily deploy to [Vercel](https://vercel.com).
